## 1. 目标与不做

**目标**：实现 Tile 级 `TileAmAllocator` + `ChainTable` 硬件：每 Tile 8 槽（4 groups×2）、每 context ≤2 live lease、bundle 预留、一次申请+挂起+slot_free 恰好一次唤醒、授予线性化点全成或全败、`(group,index)` 首空闲 slot 选择、least-live engine 选择与不可变 affinity、自锁 ERROR、请求串行化点。功能层先行（Chisel 状态机/寄存器实现，可用抽象 AM 存储，不伪造周期/RTL 时序）。

不实现完整RMW/drain（P16/P17）、事件槽/故障quiesce（P15）、RoCC/固件。1/2engine仲裁以受控engine接口验证模块合同；真实多array并行及T04/T20完整覆盖归P26，不由单阵列P18外推。

## 4. 输入输出、接口与不变量

- AM_REQUEST 一次发出：GRANTED（lease/bound_engine/completion_token）/PARKED(request_id)/ERROR(reason)；PARKED 无 slot/quota/generation/半初始化资源副作用；每 owner 至多一条挂起请求，队列深度=每 Tile context 数。
- 授予线性化点一次取得：slot + quota++ + ChainTable 项 + current+next mailbox + 已准入 L1 输出绑定 + owner/generation + 不可变 bound_engine，置 RESERVED；**completion_token 只是完成事件引用，授予不取得也不等待事件槽**（P15 验证跨模块组合，本模块接口不得出现事件槽请求线）。
- 选择规则（确定性，进 target fingerprint）：slot 取 `(group,index)` 序首个空闲；bound_engine 与 group 独立，取本 Tile 已绑定 live handle 最少的 engine，平局最小 ID；可绑定忙 engine。**注意**：empty 启动+不迁移前提下每 engine ≤2 是 4/8 均衡分布的策略结果，不是硬件 2-handle 隐限；任何 metadata/断言不得编码每 engine 上限 2。
- grantable（每 slot_free/CANCEL 在同一串行化点重评估）：fresh 需 `free−Σreserved ≥ bundle` 且无更早挂起 fresh（FIFO 不插队）；continuation 需自身预留≥1、|L|<2、同 logical_am 无任何 live lease（含 FINAL 已受理未 slot_free）。
- 永久 ERROR（不挂起，context fault）：§4.1 reason 全集；其中「未受理 FINAL 的链数达 bundle 再申请」为自锁错误，**必须 ERROR/fault 而非挂起**。同 logical_am 有 FINAL 已受理未释放的 live 链 → 新申请挂起至 slot_free（可挂起条件，非错误）。
- CANCEL(owner)：丢弃挂起请求（永不唤醒）；lease 回收的 quiesce 细节归 P15，本模块保证不再向已取消请求交付。
- ChainTable 字段：owner_ctx_key、logical_am、output_chain_id、group/region、bound_engine、shape/acc_format/layout、submitted/issued/committed 游标、final_issued、generation。

## 5. 实施步骤

1. 实现allocator/ChainTable真实寄存器状态机；对RMW/drain生命周期由有界受控testbench握手驱动，明确这是分配器RTL模块级验证，不伪称完整数据通路。所有状态/游标真实实现，不留空状态分支；P18接入真实服务后再验端到端。
2. 串行化点实现：授予判断、入队、slot_free 重评估、CANCEL 全部在同一 `step` 内序贯完成；构造 park 与 slot_free 同拍、cancel 与 grant 同拍的定向测试（无丢/重复唤醒）。
3. slot/engine 选择器实现并输出选择 trace（handle→group/region/engine），供 fingerprint 与 T04/T05 断言。
4. mailbox 配额（current+next）与 submitted/issued/committed 游标接线；FULL 语义：不受理、不增游标、返回 FULL。
5. 场景测试 T01–T06/T08/T13/T21、Q01–Q06 功能层（Q04/Q06 用 quota=1/2 两配置）；Q08 分配器部分：实例化两个 `TileAmAllocator`（Tile0/Tile1 harness，仅 RTL 隔离 harness，FPGA 板级仍单 Tile）证明 Tile0 满槽/错误不影响 Tile1。
6. 注册 `boa-allocator` target（config 支持 `--case`），产出 manifest/summary（request/grant/park/wake/cancel 计数、每 case 断言）；更新 evidence。

- 产物：allocator/ChainTable/挂起 FIFO 模块、1/2-engine 配置实例、`boa-allocator` target、选择规则 fingerprint、evidence。
