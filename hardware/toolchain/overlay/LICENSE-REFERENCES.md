# Upstream license references (P02 overlay + smoke)

This overlay compiles pinned upstream sources in place; no upstream source text
is duplicated here. All licenses remain with their upstream repositories at the
pins recorded in `hardware/toolchain/toolchain.lock` (generated by the P02
parent after the real build). In-image locations follow the P02 contract:
`/opt/deps/chipyard` (NEXUS_DEPS), `/workspace/hardware/gemmini/upstream`
(NEXUS_GEMMINI, `/opt/gemmini/upstream` during image build), `/opt/deps/softfloat`.

Notes:

- The smoke sources written for P02 (`hardware/toolchain/smoke/*` and the
  overlay's own Scala files under `hardware/toolchain/overlay/local/p02/`) are
  original Nexus work, BSD-3-Clause, consistent with this repository.
- Where this table says "see upstream file", the authoritative license text is
  the file at the pinned commit; the entry here is an unverified convenience
  label and the pinned file wins.
- Chipyard itself is used only for its sbt project graph, pins, and build
  metadata; its `generators/gemmini` checkout is intentionally never referenced
  (single authoritative Gemmini source at `NEXUS_GEMMINI`).
